# CSS

This folder contains the stylesheets for the front-end pages.

## Files

- `auth.css` styles the sign-in and account entry pages.
- `dashboard.css` styles the dashboard and method overview cards.
- `login.css` styles the login verification page, including the webcam panel and method status panel.
- `register.css` styles the authentication setup page, including method guidance, recording controls, and setup progress.

## Notes

Keep page-specific styling in the matching CSS file so each screen stays easy to update. If a style is shared across many pages, consider moving it into a shared stylesheet later.
