# Frontend Pages (HTML)

## Overview
This folder contains the main HTML pages for the Graphical Password Authentication System.  
They handle the user interface and authentication flow.

## Pages

- **index.html** – Sign up (username + email)
- **signin.html** – Existing user login (connects to backend)
- **register.html** – Set up authentication methods (gesture, face, voice, Face ID)
- **login.html** – Perform authentication checks
- **dashboard.html** – Access after login (view/update methods, logout)

## Flow
index → register → signin → login → dashboard
