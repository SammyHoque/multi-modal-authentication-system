# Frontend – GraphicalPass Authentication System

## Overview

This folder contains the frontend implementation for the **GraphicalPass** authentication system.

The frontend provides a multi-modal graphical authentication experience, allowing users to register and log in using gesture, facial motion, voice, and Face ID methods.

It is built using **HTML**, **CSS**, and **JavaScript**, and integrates with a backend server for storing and retrieving authentication data.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- MediaPipe (Hands & Face Landmarker)
- Web Speech API (for passphrase recognition)
- MediaRecorder API (for audio capture)
- Web Audio API (for audio processing)
- Fetch API (for backend communication)
