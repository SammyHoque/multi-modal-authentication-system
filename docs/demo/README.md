# Demo

This folder contains demonstration materials for the project **Graphical Passwords: Preventing Shoulder Surfing**.

## Contents
- Demo videos showing the gesture recognition prototype in action.
- Prototype code used for early testing of gesture-based authentication.
- Any supporting assets related to system demonstrations or presentations.

The demos here are used to visually demonstrate progress and functionality.  
They are not part of the final implementation found in the `/src` folder.
