# Backend – GraphicalPass Authentication System

## Overview

This backend provides the server-side functionality for the **GraphicalPass** authentication system. It handles user registration, authentication method storage, and retrieval of biometric authentication data.

The backend is built using **Node.js**, **Express**, and **PostgreSQL**, and replaces the earlier client-side `localStorage` approach with a more secure, database-driven architecture.

---

## Technologies Used

- Node.js
- Express.js
- PostgreSQL
- pg (node-postgres)
- dotenv
- CORS
